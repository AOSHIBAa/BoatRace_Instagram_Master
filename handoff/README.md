# handoff: Claude ↔ ChatGPT の画像受け渡し

- `handoff/requests/YYYY-MM-DD.md` : Claude が置く画像の依頼書(毎朝9時まで)
- `handoff/images/YYYY-MM-DD/cover.png` : ChatGPT が置く生成画像(毎日11時ごろ)
- 13時台に Claude が画像を確認して投稿に使う。画像がない日は Claude の表紙に切り替える。

## 画像のルール(ChatGPT向け)
- 縦長 1080x1350 相当(4:5)。PNG。
- **画像の中に文字を一切入れない**(特に「AI」の文字は厳禁)。タイトル文字は Claude が後から重ねる。
- 実在の選手・人物の顔、BOAT RACE などの公式ロゴ、艇番の公式デザインそっくりの意匠は入れない。
- 画面の上半分はタイトルを重ねるため、暗めでシンプルにする。
